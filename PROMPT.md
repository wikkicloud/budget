# Промпты для Claude Code

Запускайте по одному. Следующий — только когда предыдущий собрался и работает.

## Шаг 1 — каркас и данные

Прочитай CLAUDE.md. Мы делаем приложение для ведения бюджета с четырьмя экранами: «Расходы», «Приход», «Кошельки», «Аналитика». Навигация — нижняя панель (Bottom Navigation).

Сейчас сделай только фундамент:
1. Настрой Hilt, Room, Navigation Compose.
2. Создай сущности Wallet, Category, Transaction, DAO и репозиторий по модели из CLAUDE.md.
3. Предзаполни категории и два стартовых кошелька: «Наличные» (CASH) и «Карта» (CARD).
4. Сделай нижнюю навигацию с четырьмя пустыми экранами-заглушками.
Собери проект через ./gradlew assembleDebug и исправь ошибки. Потом закоммить.

## Шаг 2 — экран «Кошельки»

Сделай экран «Кошельки»: список кошельков (название, тип, текущий баланс), кнопка добавления кошелька (название, тип «Карта/Наличные», начальная сумма), редактирование и удаление (удалять кошелёк с операциями нельзя — показать предупреждение). Сверху — общая сумма по всем кошелькам. Собери и закоммить.

## Шаг 3 — экран «Расходы»

Сделай экран «Расходы»: форма (сумма, описание, выпадающий список категорий, выбор кошелька — карта конкретная или наличные) и кнопка «Сохранить». Ниже — список последних расходов с возможностью удалить или изменить. После сохранения баланс кошелька должен уменьшаться. Валидация: сумма > 0, кошелёк выбран. Собери и закоммить.

## Шаг 4 — экран «Приход»

Сделай экран «Приход»: сумма, выбор кошелька, необязательное описание, кнопка «Сохранить». Ниже — список последних приходов с удалением. Баланс кошелька должен увеличиваться. Собери и закоммить.

## Шаг 5 — экран «Аналитика»

Сделай экран «Аналитика»:
- переключатель периода: неделя / месяц / год / выбранный диапазон;
- круговая диаграмма расходов по категориям с легендой и суммами;
- столбчатая или линейная диаграмма «доходы vs расходы» по дням/месяцам;
- карточки: итого расходов, итого доходов, разница;
- по желанию — расходы по кошелькам.
Если данных нет, показывай понятную заглушку. Собери и закоммить.

## Шаг 6 — полировка

Пройдись по приложению: тёмная тема, пустые состояния, форматирование сумм, поворот экрана, иконка приложения. Напиши unit-тесты на расчёт баланса и форматирование денег. Запусти ./gradlew test и ./gradlew lint.

## Идеи на потом

- Свои категории и их редактирование
- Экспорт в CSV, резервная копия
- Бюджетные лимиты по категориям с уведомлением
- Повторяющиеся операции
